Instructions pour GrapeJS - Partenaires Master User Go Exploria

Ce bloc est entièrement éditable via GrapeJS. Tous les éléments avec l'attribut data-gjs-editable="true" peuvent être modifiés directement dans l'interface.

Éléments clés de cette section :
  • En-tête avec badges : "Partenaires", "Master", "User", "Go", "Exploria" - Chaque badge est éditable séparément
  • Slogan principal : "ACTIVEZ ET GÉREZ VOS DESTINATIONS ET VOS MARCHÉS" - Mettez en valeur votre proposition
  • Fonctionnalités : 4 cartes détaillant les principales fonctionnalités de la plateforme
  • Dashboard : Aperçu visuel avec statistiques impactantes
  • Avantages exclusifs : Liste des bénéfices pour les partenaires
  • Partenaires showcase : Logos et noms des entreprises partenaires
  • Call-to-action : Boutons pour conversion (démo, contact)
Pour personnaliser :
  • Couleurs : Modifiez les valeurs #1a3a8f (bleu foncé) et #2d5cc2 (bleu clair) dans le CSS
  • Contenu : Cliquez sur n'importe quel texte pour le modifier
  • Structure : Les blocs avec data-gjs-type peuvent être réorganisés dans GrapeJS
  • Icônes : Remplacez les classes FontAwesome par d'autres icônes de la bibliothèque
