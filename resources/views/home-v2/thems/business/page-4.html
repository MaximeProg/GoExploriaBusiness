Contrôles d'édition

Instructions d'utilisation

  • Cliquez sur "Activer l'éditeur" pour modifier la section partenaires
  • Dans l'éditeur, vous pouvez modifier le texte, les images et la mise en page
  • Pour modifier une image, cliquez dessus puis utilisez l'icône d'image dans le panneau de droite
  • Pour ajouter un nouveau partenaire, cliquez sur le "+" dans le panneau de gauche
  • Cliquez sur "Exporter le HTML" pour obtenir le code de votre section
  • Les filtres de région fonctionnent en mode visualisation seulement
